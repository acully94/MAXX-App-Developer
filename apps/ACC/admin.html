Match Centre Admin

Settings save to the Match Centre server, so they apply everywhere — update them here from your phone or laptop and they'll appear on the TV automatically within 30 seconds, no need to be on the same device.

Live Scores (Play-Cricket)

Add a Play-Cricket Match ID to any of the 4 slots to pull live scores automatically every 5 seconds. A slot with no Match ID will just show its team name until one is added.

Advanced: Match Centre server URL

Only needed if you've redeployed the Cloudflare Worker to a new address — leave this blank to use the default one. This setting is local to this browser only (unlike everything else on this page, which is shared).

Featured Match

Pick which of the 4 fixture slots below gets the big featured panel. If that match is being live streamed on YouTube, turn the toggle on and paste in the video ID (the part after "v=" or "youtu.be/" in the video's link) — the Match Centre will show the video and hide its own score/batting overlay. Turn it off to show the live scorecard details instead.

Club Sponsors

Shown one at a time, slideshow-style — upload one or more images and set how many seconds each one displays before moving to the next. Leave empty to hide the sponsor panel entirely (club news will take the full width instead). Uploaded images are stored on the Match Centre server, so keep them reasonably small (a few hundred KB each).
